# 06. 로그인·조직·권한·관리자

> 관련: ORCHESTRATION D1·D2 · 07 데이터 모델·보안 규칙 · 09 배포 (환경변수)

## 1. 로그인 방식 (Firebase Authentication)

| 방식 | 1차 | 설명 |
|---|---|---|
| 구글 | ✅ | 가장 간단, 버튼 하나 |
| 이메일 링크 | ✅ | 비밀번호 없이, 이메일로 온 링크를 누르면 로그인 (비밀번호를 잊어버릴 일 없음) |
| 카카오 | 2차 | Firebase 기본 제공이 아님 → OpenID 연결 방식을 쓰려면 Firebase 인증의 상위 단계(Identity Platform) 전환이 필요할 수 있음. 2차에서 조건·비용 확인 후 결정 |

### 로그인 화면
```
        AI 가이드에 로그인

   [ G  구글로 계속하기 ]          ← 검은 알약
   ───────── 또는 ─────────
   이메일 [                    ]
   [ 로그인 링크 받기 ]

   초대코드가 있으신가요? →
```

## 2. 로그인 유지 방식

- 브라우저: Firebase 로그인 → 받은 신분 토큰을 서버(Vercel)로 보내 **세션 쿠키**로 바꿔 저장 (Admin SDK `createSessionCookie`, 유효 14일)
- 서버(페이지 그리기 전): 세션 쿠키를 확인해서 로그인 여부·조직 멤버 여부를 먼저 판단 → 권한 없는 화면은 아예 그리지 않고 이동시킴
- 로그아웃: 쿠키 삭제 + Firebase 로그아웃
- **최종 방어선은 Firestore 보안 규칙** (07) — 화면 쪽 검사를 우회해도 데이터는 못 읽음

## 3. 조직 가입: 초대코드

```
관리자: 조직 관리 → 멤버 → [초대코드 만들기] (권한·만료일·사용 횟수 선택)
        → 코드(예: JEJU-7K2Q)와 링크(/ko/join?code=JEJU-7K2Q) 생성 → 카톡 등으로 전달
멤버:   링크 클릭 → (로그인 안 돼 있으면 로그인) → 서버가 코드 확인 → 멤버로 등록 → 조직 첫 전시관
```
- 코드 확인·멤버 등록은 **반드시 서버(Vercel)에서 Admin SDK로** 처리 (사용자가 스스로 멤버 문서를 만들 수 없게 규칙으로 막음)
- 한 번에 처리(트랜잭션): 코드 유효성 → 사용 횟수 +1 → 멤버 문서 생성 → 내 조직 목록에 추가
- 코드 형식: 헷갈리는 글자(0/O, 1/I/L) 빼고 대문자+숫자 8자리, 앞에 조직 약칭
- 실패 안내: "만료된 코드예요" / "이미 가입된 조직이에요" / "코드를 다시 확인해 주세요"

## 4. 권한 3단계

| 권한 | 저장 위치 | 할 수 있는 것 |
|---|---|---|
| 운영자 `platformAdmin` | Firebase 사용자 고유 표시(custom claim) | 모든 조직 생성·수정, 공통 콘텐츠 관리, 전시관 종류 관리 |
| 조직 관리자 `admin` | `orgs/{org}/members/{uid}.role` | 우리 조직 멤버 초대·내보내기, 전시관 켜기·끄기·순서, 조직 전용 콘텐츠, 공통 콘텐츠 숨기기·순서, 브랜딩 |
| 멤버 `member` | 같은 곳 | 둘러보기, 실행, 즐겨찾기 |

- 운영자 지정: 처음 한 번 스크립트로 `jejuailabs@gmail.com` 계정에 `platformAdmin` 표시 부여 (09 §3)
- 한 사람이 조직마다 다른 권한 가능 (A에서는 관리자, B에서는 멤버)

## 5. 조직 선택
- 내 조직 목록: `users/{uid}.orgIds`
- 0곳: "초대코드를 입력해 주세요" 화면 (+ 체험용 공통 AI 전시관)
- 1곳: 바로 이동
- 2곳 이상: 마지막 조직(`lastOrgId`)으로 이동, 상단 조직 이름 누르면 목록

## 6. 조직 관리자 화면 (`/{lang}/o/{org}/admin`)

쉬운 구조를 위해 **탭 4개**만 둡니다.

| 탭 | 내용 |
|---|---|
| 멤버 | 목록(이름·이메일·권한·가입일), 권한 바꾸기, 내보내기, 초대코드 만들기·목록·끄기 |
| 전시관 | 전시관 목록 + **켜기/끄기 스위치** + 끌어서 순서 바꾸기 + 이름 바꾸기 (언어별) |
| 콘텐츠 | 전시관 고르기 → 공통 콘텐츠 숨기기·순서 / 조직 전용 콘텐츠 추가·수정·삭제 (언어별 입력 칸) |
| 꾸미기 | 조직 이름, 로고, 기본 색상 테마, 기본 언어, 사용 언어 |

- 바꾸면 바로 저장되고 멤버 화면에 바로 반영
- 삭제는 "정말 지울까요?" 확인 후, 실제로는 `status: 'archived'`로 숨김 (되살리기 가능)

## 7. 운영자 화면 (`/{lang}/platform`)
- 조직 만들기 (이름, 주소 이름, 첫 관리자 이메일 → 관리자용 초대코드 자동 생성)
- 공통 콘텐츠 관리 (조직 관리자 화면의 콘텐츠 탭과 같은 화면 재사용)
- 전체 조직 목록·멤버 수

## 8. 완료 조건
- **P2**: 구글·이메일 링크 로그인, 초대코드 가입, 조직 선택, 로그아웃. 다른 조직 문서 읽기 시도가 규칙에서 거부됨 (07 규칙 테스트 통과)
