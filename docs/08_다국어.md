# 08. 다국어

> 관련: ORCHESTRATION D5 · 02 디자인 (글꼴) · 07 데이터 모델 (번역 필드)

## 1. 지원 언어

| 코드 | 언어 | 표시 이름 | 단계 |
|---|---|---|---|
| `ko` | 한국어 | 한국어 | 기본, 1차 |
| `en` | 영어 | English | 1차 |
| `ja` | 일본어 | 日本語 | 2차 |
| `zh` | 중국어 (간체) | 简体中文 | 2차 |

- 새 언어 추가 = 언어 목록에 코드 한 줄 + `messages/{코드}.json` 파일 하나 (코드 수정 최소)

## 2. 번역 대상은 두 종류

| 종류 | 예시 | 저장 위치 | 누가 관리 |
|---|---|---|---|
| **화면 문구** | 메뉴 이름, 버튼, 안내 문구 | `messages/ko.json` 등 (코드와 함께) | 개발 |
| **콘텐츠** | AI 설명, 프롬프트, 퀴즈 문제, 조직 이름 | Firestore의 번역 필드 `{ko, en, ...}` | 운영자·조직 관리자 |

## 3. 화면 문구 (next-intl)

### 주소와 언어
- 주소 맨 앞이 언어: `/ko/o/jeju-a/ai`, `/en/o/jeju-a/ai`
- 처음 들어오면 언어를 정하는 순서: ① 주소에 있는 언어 ② 내가 전에 고른 언어(쿠키) ③ 내 정보 `prefs.locale` ④ 브라우저 언어 ⑤ 조직 기본 언어 ⑥ `ko`
- 조직이 사용 언어를 제한하면(`locales`), 보기 설정에 그 언어만 나옴

### 파일 구성
```json
// messages/ko.json  (화면 영역별로 묶음)
{
  "shell":  { "settings": "보기 설정", "darkMode": "어두운 화면", "search": "검색" },
  "halls":  { "ai": "AI 전시관", "prompts": "프롬프트 전시장", "tools": "AI 도구", "games": "게임" },
  "item":   { "openSite": "사이트 열기", "openApp": "앱으로 열기", "more": "자세히", "copy": "복사" },
  "launch": { "appMissing": "이 컴퓨터에 앱이 없는 것 같아요" },
  "auth":   { "google": "구글로 계속하기", "emailLink": "로그인 링크 받기" }
}
```
- 화면 코드에 한국어를 **직접 쓰지 않음** → 모두 `t('item.openSite')`처럼
- 숫자·날짜는 언어별 형식으로 (`Intl` 사용, 예: 2026. 10. 7. / Oct 7, 2026)

### 누락 검사
- `ko.json`을 기준으로 다른 언어 파일에 빠진 키가 있는지 검사하는 스크립트 `npm run i18n:check`
- 빠진 문구는 화면에서 **한국어로 대신 표시** (빈칸이나 키 이름이 보이면 안 됨)
- 배포 전 자동 점검에 포함 (09)

## 4. 콘텐츠 번역

### 표시 규칙
```
보여줄 언어 = 지금 화면 언어 → 없으면 조직 기본 언어 → 없으면 ko
```
```ts
// src/i18n/pick.ts
export const pick = (v: L10n | undefined, locale: Locale, orgDefault: Locale) =>
  v?.[locale] ?? v?.[orgDefault] ?? v?.ko ?? '';
```
- 번역이 없어서 다른 언어로 대신 보여줄 때, 관리자에게만 작은 "번역 없음" 표시

### 관리자 입력 화면
- 콘텐츠 편집 칸마다 **언어 탭** (한국어 | English | 日本語 | 中文), 한국어만 필수
- 목록에서 "번역 안 된 콘텐츠만 보기" 필터
- (2차) "자동 번역 초안 만들기" 버튼 — AI로 초안을 채우고 사람이 확인

## 5. 언어 바꾸기 화면
- 보기 설정(⚙) 맨 위 "언어" — **각 언어를 그 언어로** 표시 (한국어 / English / 日本語 / 简体中文)
- 바꾸면 같은 화면의 다른 언어 주소로 이동 (보고 있던 카드, 스크롤 유지)
- 로그인 상태면 `prefs.locale`에도 저장

## 6. 언어별 주의
- `<html lang="…">` 언어에 맞게 (화면 읽기 프로그램·글꼴 선택에 필요)
- 글꼴: 일본어·중국어는 해당 글꼴로 대체 (02 §4)
- 영어는 한국어보다 길어지는 경우가 많음 → 버튼·탭은 글자가 길어져도 줄바꿈되거나 말줄임 되게 설계
- 한국어 줄바꿈은 단어 단위, 일본어·중국어는 기본 줄바꿈

## 7. 완료 조건
- **P1**: 한국어·영어 화면 문구 전환, 주소 언어 유지, 누락 검사 스크립트 동작
- **P3 이후**: 각 전시관이 영어에서 깨지지 않음, 콘텐츠 번역 없을 때 한국어로 대신 표시
- **2차**: 일본어·중국어 추가
