## 2. 화면

### 2026-10-08: 관리자 카테고리 관리
- `/ko/admin`·`/en/admin`에 공용 AI·카테고리 관리 화면을 제공한다. 기존 플랫폼 운영자 권한을 사용하며 메인과 계정 메뉴에서 진입한다. AI 추가·수정·공개·숨김, 정렬 순서와 여러 카테고리 선택을 지원한다.
- 카테고리 이름(한국어·영어)·순서·표시 여부와 새 카테고리를 Firestore `settings/aiCategories`에 저장한다. ‘전체’는 고정이며 숨긴 카테고리와 AI의 연결은 유지한다. 같은 설정을 여러 창에서 수정하면 이전 버전 저장을 거절해 덮어쓰기를 막는다.
- 기존 AI의 분류는 처음 편집할 때 현재 기본값으로 채운다. 저장 후에는 관리자가 선택한 분류만 사용하며 이미지 분류를 해제해도 코드의 기본값을 다시 합치지 않는다. 공개 카탈로그와 조직 전시관 모두 같은 분류를 사용한다.
- 모바일 카테고리는 선반 위에 놓고 스크롤 중에도 접근할 수 있게 유지한다. PC는 선반 아래 위치를 유지한다. 새 AI는 기본 커버 또는 기존 브랜드 커버를 선택한다.

### 2026-10-08: 바로가기·QR·모바일 앱
- 메인에 바탕화면 바로가기와 휴대폰 QR 버튼을 둔다. 전용 선반 아이콘, 웹 앱 manifest, iPhone 홈 화면 아이콘을 제공하며 지원 브라우저에서 설치 창을 연다. 설치 창을 제공하지 않는 브라우저에는 해당 기기의 추가 절차를 안내한다.
- QR은 현재 언어의 배포 메인 주소를 표시한다. 로컬 미리보기에서도 휴대폰이 접근할 수 있는 `aiguidepage.vercel.app` 주소를 쓰며 이미지 저장·주소 복사를 지원한다.
- 모바일에서는 서비스가 발행한 App Links·Universal Links를 확인한 경로만 연결한다. Android는 공식 앱 식별자가 있는 서비스의 Intent와 웹 대체 주소, iOS는 공식 Universal Link를 사용한다. 일반 채팅을 Claude Code 링크로 대신 열지 않는다.
- ChatGPT: iOS `https://chatgpt.com/#native`, Android `com.openai.chatgpt`. Claude: `/new`, `com.anthropic.claude`. Grok: `/`, `ai.x.grok`. Perplexity: `/search`, `ai.perplexity.app.android`. NotebookLM: `/`, `com.google.android.apps.labs.language.tailwind`. Suno: `/create`, `com.suno.android`. Gemini는 Android `com.google.android.apps.bard`만, Flow Music은 iOS 공식 사이트만 연결한다. Genspark·영상 Flow 및 확인되지 않은 OS는 웹으로 제공한다.
- 출처는 각 공식 도메인의 `/.well-known/assetlinks.json`과 `/.well-known/apple-app-site-association`(10-08 확인), [Android Intent 안내](https://developer.chrome.com/docs/android/intents), [Chrome 설치 안내](https://support.google.com/chrome/answer/9658361)다. 실제 앱 실행은 설치 여부와 기기의 링크 설정에 따른다.

### 승인된 시안과 반응형 구현 기준 (2026-10-07)
- 기준 이미지: `output/imagegen/homepage-shelves-v1.png`. 밝은 회색 벽, 깊이 있는 흰 선반, 선반에 바닥이 닿는 앨범 커버, 부드러운 접촉 그림자를 유지한다.

### 카드 (정사각)
- 1차: AI 로고(가운데) + 서비스 고유색 또는 테마 강조색 배경 + 아래 이름
- 2차: 커버 이미지(`coverUrl`)가 있으면 앨범 커버처럼 이미지로 교체
- 마우스 올리면: 떠오름 + `[열기]` `[설명]` 보조 버튼 (휴대폰은 마우스가 없으니 바로 크게 보기)
- 카드 왼쪽 위 작은 배지: `즐겨찾기 ★`, `새로 추가` 등

## 4. 실행: 사이트 열기 / 앱으로 열기

### 4-1. 사이트 열기
- 새 탭으로 엽니다 (`target="_blank"`, `rel="noopener"`)
- 열 때 사용 기록 남기기 (07 `events`, 선택 사항)

### 4-2. 앱으로 열기 — 조건부 기능
웹페이지는 보안상 컴퓨터 프로그램을 마음대로 실행할 수 없습니다. **앱이 설치될 때 등록한 전용 주소**(예: `claude://`)가 있을 때만 열 수 있습니다.

동작 순서 (2026-10-07 개정):
```
[앱으로 열기] 클릭
 → 전용 주소로 열기 시도
 → 브라우저가 "○○ 앱을 여시겠어요?" 확인창을 띄움 (처음 한 번)
 → 안내: "앱 열기를 요청했어요. 브라우저에서 확인창이 뜨면 열기를 선택해 주세요."
 → 웹 열기와 앱 설치 안내를 계속 제공
```
- 휴대폰에서는 `앱으로 열기` 버튼을 숨기고 사이트 열기만 (휴대폰은 앱이 있으면 사이트 주소가 알아서 앱으로 열리는 경우가 많음)
- 타이머·탭 가림·포커스 변화로 앱 설치 여부나 실행 성공을 단정하지 않는다. 요청이 실패해도 웹으로 자동 이동하지 않으며 사용자가 웹 열기를 직접 선택한다.
- 데이터: `desktopApp`에 실행 주소, 공식 설치 안내, 지원 OS, 출처와 확인일을 저장한다. 지원 정보가 없는 서비스·OS와 휴대폰에는 앱 버튼을 표시하지 않는다.
- 현재 Claude만 연결: `claude://claude.ai/new`, 설치 안내 `https://claude.com/download`, Windows/macOS/Linux. 공식 문서와 이 PC의 Windows 프로토콜 등록을 확인했다. 브라우저 → 실제 앱 실행은 P8 실기 확인 항목으로 남긴다.
- ChatGPT의 새 데스크톱 문서에는 `codex://`가 나오지만, 기존 ChatGPT 앱과 목적 화면이 다를 수 있어 현재 카드에 임의 연결하지 않는다. 다른 AI도 실행 대상·OS를 확인한 뒤 추가한다.
- 출처: [Claude 공식 실행 주소](https://support.claude.com/en/articles/14729294-open-claude-desktop-with-a-link), [ChatGPT 데스크톱 명령](https://learn.chatgpt.com/docs/reference/commands#deep-links).

### 4-3. (확장) 설치형 프로그램
어떤 프로그램이든 실행해야 하는 요구가 생기면, 같은 화면을 감싸는 설치형 프로그램(Tauri 등)을 따로 만들 수 있습니다. 지금 구조를 바꿀 필요는 없고 1차 범위가 아닙니다.
