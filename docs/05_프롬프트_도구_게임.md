## A. 프롬프트 전시장 (`feed`)

### A-1. 카드 구성
```
┌──────────────────────────────────┐
│ (ChatGPT 아이콘) 글쓰기 · 생활      │
│ 칠순 잔치 인사말 만들기             │  ← 제목
│ ┌──────────────────────────────┐ │
│ │ 어머니 칠순 잔치에서 할 인사말을 │ │  ← 프롬프트 본문 (4줄 넘으면 접힘)
│ │ 3분 분량으로 따뜻하게 써줘…    │ │
│ └──────────────────────────────┘ │
│ (결과 예시 이미지 또는 글, 선택)     │
│ [복사]  [ChatGPT에서 열기 ↗]   ☆  │
└──────────────────────────────────┘
```
- 빈칸이 있는 프롬프트: `{{이름}}`처럼 표시 → 크게 보기에서 빈칸 입력 칸이 생기고, 채우면 완성된 문장으로 복사됨

### A-2. 무한 스크롤
- 처음 12개 → 목록 끝에서 화면 높이 1개 정도 남았을 때 다음 12개 (화면에 들어오는 것 감지 방식)
- Firestore의 "여기서부터 다음 12개" 방식(커서) 사용, 정렬은 `order` → `createdAt`
- 로딩 중: 뼈대 카드 3개 / 끝: "모두 봤어요" 문구 / 실패: [다시 시도] 버튼
- 공통 프롬프트와 조직 전용 프롬프트는 각각 커서를 두고 합쳐서 보여줌 (07 §3)
- 스크롤 위치 기억: 크게 보기 열었다 닫아도 그 자리 유지

### A-3. AI에서 바로 열기
- 일부 AI는 주소에 질문을 담아 열 수 있음 → 열리면 프롬프트가 입력된 상태
- 데이터: AI 콘텐츠의 `promptUrlTemplate` (예: `https://www.perplexity.ai/search?q={q}`)
- 값이 없거나 동작이 확인되지 않은 AI는: **복사한 뒤 사이트를 열고** "붙여넣기(Ctrl+V) 하세요" 안내
- ✅ AI별로 실제 동작 여부를 P5에서 확인하고 데이터에 반영 (서비스가 언제든 바꿀 수 있으므로 확인 날짜도 기록)

### A-4. 필터
- 칩: 전체 · 글쓰기 · 이미지 · 영상 · 업무 · 생활 (조직이 칩 목록을 바꿀 수 있음)
- AI별 보기: 카드 위 AI 아이콘을 누르면 그 AI용 프롬프트만

## B. AI 도구 (`pegboard`)

### B-1. 도구 구조
도구 하나 = **독립된 작은 부품** 하나. 도구는 등록부에 등록하고, 어떤 조직에 보일지는 데이터로 정합니다.
```ts
// src/tools/registry.ts
export const tools = {
  'prompt-builder': lazy(() => import('./prompt-builder')),
  'char-count':     lazy(() => import('./char-count')),
  'qr-maker':       lazy(() => import('./qr-maker')),
  'image-shrink':   lazy(() => import('./image-shrink')),
};
```
- 도구 데이터(`tool` 콘텐츠)에는 `toolKey`(위 이름)와 설정값(`config`)만 저장
- **같은 도구를 조직마다 다른 설정으로** 쓸 수 있음 → 예: 안내문 틀 도구에 A 조직은 행사 안내문 틀, B 조직은 회의록 틀
- 도구는 처음 열 때만 불러옴 (전시관 첫 로딩을 가볍게)

### B-2. 1차 도구 후보
| 도구 | 키 | 하는 일 | 인터넷 필요 |
|---|---|---|---|
| 프롬프트 도우미 | `prompt-builder` | 목적·대상·분량·말투를 고르면 프롬프트 문장 완성 → 복사 / AI에서 열기 | 아니오 |
| 글자 수 세기 | `char-count` | 글자 수(공백 포함·제외), 원고지 매수 | 아니오 |
| QR코드 만들기 | `qr-maker` | 주소 입력 → QR 그림 저장 | 아니오 |
| 사진 용량 줄이기 | `image-shrink` | 사진을 올리면 기기 안에서 줄여서 저장 (서버로 안 보냄) | 아니오 |
| 서식 틀 | `template-fill` | 조직이 정한 틀(행사 안내문, 회의록 등)에 빈칸 채우기 | 아니오 |

- 1차는 **서버로 아무것도 보내지 않는 도구**만 → 개인정보 걱정 없음
- AI를 직접 호출하는 도구(요약 등)는 요금·키 관리가 필요해 2차 이후 검토

### B-3. 작업대 (크게 보기)
- 카드가 아래로 내려오며 커지고 그 안에서 도구가 바로 실행
- 위: 도구 이름 + 한 줄 설명 / 가운데: 도구 / 아래: `[처음으로]` `[닫기]`

## C. 게임 (`arcade`)

### C-1. 게임 구조
도구와 같은 방식: 게임 하나 = 독립 부품, 등록부(`src/games/registry.ts`)에 등록, 조직 노출은 데이터로.

### C-2. 1차 게임 후보
| 게임 | 키 | 비고 |
|---|---|---|
| 짝 맞추기 | `memory-match` | AI 로고 카드 짝 맞추기, 난이도 3단계 (어르신 두뇌 운동) |
| AI 상식 퀴즈 | `ai-quiz` | 문제는 데이터(`config.questions`)로 → 조직마다 다른 문제 가능 |
| 2048 | `2048` | 방향키·밀기 |

- 게임도 다국어 (문구는 `messages/`, 퀴즈 문제는 콘텐츠 번역 필드)
- 점수는 1차에서는 기기에만 저장 (순위표는 2차)

### C-3. 조직별로 끄기
- 조직 설정에서 `games` 전시관을 끄면 상단 메뉴·검색에서 모두 사라짐
- 주소로 직접 들어와도 "이 조직에서는 사용하지 않는 메뉴예요" 안내 후 첫 전시관으로
