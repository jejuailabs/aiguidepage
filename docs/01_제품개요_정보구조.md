# 01. 제품 개요·정보 구조

> 관련: ORCHESTRATION §1~2 · 02 디자인 · 03 전시관 엔진 · 06 로그인

## 1. 누가 쓰나

| 사용자 | 설명 | 핵심 요구 |
|---|---|---|
| 방문자 | 로그인 전 | 무엇을 하는 곳인지 바로 알고, 체험해 보고, 로그인 |

| 조직 관리자 | 조직 담당자 | 멤버 초대, 우리 조직 전시관·콘텐츠 정리 |
| 운영자 | 우리 (jejuailabs) | 조직 생성, 공통 콘텐츠 관리 |

## 2. 전시관 (1차 기준 4개)

| 전시관 | 키 | 진열 방식 | 콘텐츠 | 기본 상태 |
|---|---|---|---|---|
| AI 전시관 | `ai` | 선반 `shelf` | AI 서비스 바로가기 | 모든 조직 켜짐 |
| 프롬프트 전시장 | `prompts` | 피드 `feed` | 프롬프트 예시 | 켜짐 |
| AI 도구 | `tools` | 공구 벽 `pegboard` | 간단한 도구 | 켜짐 |
| 게임 | `games` | 오락실 `arcade` | 간단한 게임 | 조직별로 선택 |

→ 전시관은 코드가 아니라 **데이터**입니다. 새 전시관 추가 방법은 03 참고.

## 3. 주소 구조

모든 주소는 언어로 시작합니다 (`ko`, `en`, `ja`, `zh`).

| 주소 | 화면 | 로그인 필요 |
|---|---|---|
| `/{lang}` | 첫 화면 (소개 + 체험 AI 전시관 + 로그인 버튼) | 아니오 |
| `/{lang}/login` | 로그인 | 아니오 |
| `/{lang}/join?code=XXXX` | 초대코드로 조직 가입 | 로그인 후 |
| `/{lang}/orgs` | 내 조직 고르기 (2곳 이상일 때만) | 예 |
| `/{lang}/o/{org}` | 조직 홈 → 첫 번째 전시관으로 바로 이동 | 예 (멤버) |
| `/{lang}/o/{org}/{hall}` | 전시관 (예: `/ko/o/jeju-a/ai`) | 예 (멤버) |
| `/{lang}/o/{org}/{hall}/{item}` | 카드 크게 보기 상태 (공유·뒤로가기용) | 예 (멤버) |
| `/{lang}/o/{org}/admin` | 조직 관리 | 조직 관리자 |
| `/{lang}/me` | 내 정보 (즐겨찾기, 보기 설정) | 예 |
| `/{lang}/platform` | 운영자 화면 | 운영자 |

- `{org}`는 조직의 영문 주소 이름 (예: `jeju-a`)
- 카드를 크게 보면 주소도 바뀝니다 → **뒤로가기 = 닫기**, 주소를 공유하면 그 카드가 바로 열림

## 4. 화면 구성

### 4-1. 공통 틀 (모든 화면)
```
┌──────────────────────────────────────────────────────────────┐
│ [조직 로고/이름]   AI · 프롬프트 · 도구 · 게임    🔍  ☀/🌙  ⚙ 👤 │  ← 상단 메뉴
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                   전시관 (진열 방식별 화면)                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```
- 상단 메뉴 가운데: **그 조직에 켜진 전시관만** 표시 (B 조직에서 게임이 꺼져 있으면 탭 자체가 없음)
- 오른쪽: 검색 · 라이트/다크 스위치 · 보기 설정(⚙: 언어·색상·글자 크기) · 내 정보
- 휴대폰: 전시관 탭은 **화면 아래 탭바**로 이동, 위에는 로고와 ☀/🌙 · ⚙만

### 4-2. 첫 화면 (로그인 전)
1. 한 줄 소개 + 검은 알약 버튼 **[로그인]**
2. 체험용 AI 전시관 (공통 AI만, 선반 진열)
3. "초대코드가 있으신가요?" 링크

### 4-3. 로그인 후 첫 화면
- 조직 1곳: 바로 그 조직의 첫 전시관 (보통 AI 전시관)
- 조직 2곳 이상: 마지막에 쓴 조직으로 바로 이동, 조직 이름을 누르면 바꾸기

## 5. 핵심 사용 흐름

### 흐름 A: AI 실행 (가장 중요, 3클릭)
```
AI 전시관 → ① 카드 클릭 (크게 보기 + 간략 설명)
          → ② [사이트 열기] 또는 [앱으로 열기]   ← 여기서 끝 (2클릭)
          → (궁금하면) [자세히] → 상세 설명 → ③ 열기
```

### 흐름 B: 프롬프트 가져다 쓰기
```
프롬프트 전시장 → 스크롤하며 구경 → ① [복사] 또는 ① [ChatGPT에서 열기]
```

### 흐름 C: 처음 가입
```
초대 링크 클릭 → 로그인 (구글 또는 이메일) → 자동으로 조직 가입 → 조직 첫 전시관
```

### 흐름 D: 관리자가 게임 끄기
```
조직 관리 → 전시관 → 게임 스위치 끄기 → 멤버 화면에서 게임 탭 사라짐
```

## 6. 검색
- 상단 🔍 → 현재 조직에 보이는 **모든 전시관의 콘텐츠**를 한 번에 검색
- 결과는 전시관별로 묶어서 표시, 누르면 해당 전시관에서 그 카드가 크게 열림
- 1차는 이미 불러온 데이터 안에서 검색 (콘텐츠 수백 개 수준 가정). 수천 개가 넘으면 검색 서비스 도입 검토

## 7. 이번 범위가 아닌 것
- 결제, 사용량 통계 대시보드, 댓글·좋아요, 푸시 알림
- 사용자 개인이 프롬프트를 올리는 기능 (조직 관리자만 추가)
