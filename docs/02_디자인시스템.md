# 02. 디자인 시스템

> 관련: ORCHESTRATION §2~3 · 03 전시관 엔진 (전시관별 분위기)

## 1. 기준: Shopify Editions에서 가져오는 것

| 요소 | 원본에서 본 모습 | 우리 규칙 |
|---|---|---|
| 배경 | 밝은 회색 벽, 가운데가 더 밝은 조명 느낌 | `--bg` + 가운데 은은한 원형 그라데이션 `--spotlight` |
| 선반 | 하얀 판, 아래 부드러운 그림자 | `--shelf`, `--shelf-shadow` |
| 카드 | 정사각, 테두리 없음, 바닥 그림자로 "놓인" 느낌 | 모서리 각짐(2px), 그림자만 |
| 주 버튼 | 검은 알약, 흰 글자 | `--accent` 배경 + `--on-accent` 글자, 완전 둥근 모서리 |
| 보조 버튼 | 반투명 회색 알약 (`Open` / `Details`) | `--chip` 배경 |
| 글자 | 작고 절제됨, 회색 보조 문구 | 단, 우리는 **어르신 대상이라 기본 크기를 키움** (§4) |
| 크게 보기 | 가운데로 튀어나옴 + 나머지 흐림 + 왼쪽에 제목·한 줄 설명 | §6 동작 규칙 |

⚠ Shopify의 로고, 커버 이미지, 문구는 사용하지 않습니다.

## 2. 테마 구조: 모드 2개 × 색상 4종 = 8가지

`<html>` 태그의 속성 두 개로 결정합니다.
```html
<html data-mode="light" data-palette="gallery">
```
- `data-mode`: `light` | `dark` (+ 사용자가 고르지 않았으면 기기 설정 따라감)
- `data-palette`: `gallery` | `ocean` | `tangerine` | `forest`
- 부품은 **토큰 이름만** 쓰고 색 값을 직접 쓰지 않습니다.

### 2-1. 공통 토큰 (모드별)

| 토큰 | 라이트 | 다크 | 쓰임 |
|---|---|---|---|
| `--bg` | `#E8E8E8` | `#121212` | 벽 |
| `--spotlight` | `rgba(255,255,255,.9)` | `rgba(255,255,255,.06)` | 가운데 조명 |
| `--surface` | `#FFFFFF` | `#1E1E1E` | 패널, 대화상자 |
| `--shelf` | `#FAFAFA` | `#2A2A2A` | 선반 판 |
| `--shelf-shadow` | `0 18px 30px rgba(0,0,0,.18)` | `0 18px 30px rgba(0,0,0,.6)` | 선반·카드 그림자 |
| `--text` | `#111111` | `#F2F2F2` | 본문 |
| `--muted` | `#6B6B6B` | `#A3A3A3` | 보조 문구 |
| `--line` | `#D6D6D6` | `#333333` | 구분선 |
| `--chip` | `rgba(0,0,0,.08)` | `rgba(255,255,255,.12)` | 보조 버튼, 태그 |
| `--scrim` | `rgba(232,232,232,.6)` + 흐림 12px | `rgba(18,18,18,.6)` + 흐림 12px | 크게 보기 뒷배경 |

### 2-2. 색상 테마 4종 (강조색만 바뀜)

| 테마 | 이름 | 느낌 | 라이트 `--accent` | 다크 `--accent` | `--accent-soft` (라이트/다크) |
|---|---|---|---|---|---|
| `gallery` | 갤러리 (기본) | 원본 그대로, 흑백 | `#111111` | `#F5F5F5` | `#EDEDED` / `#2B2B2B` |
| `ocean` | 오션 | 제주 바다, 파랑 | `#0B5CAD` | `#6BB0FF` | `#E3EFFB` / `#16283D` |
| `tangerine` | 감귤 | 따뜻한 주황 | `#B84A0E` | `#FFA45C` | `#FCEBDD` / `#3A2414` |
| `forest` | 숲 | 곶자왈, 초록 | `#1E6B45` | `#63CF98` | `#E1F2E8` / `#14301F` |

- `--on-accent`: 라이트 모드에서는 `#FFFFFF`, 다크 모드에서는 `#111111`
- 강조색이 쓰이는 곳: 주 버튼, 선택된 탭 밑줄, 스위치 켜짐, 링크, 포커스 테두리, 배경 조명에 아주 옅게 섞음
- **대비 기준**: 강조색 ↔ 배경, 글자 ↔ 배경 모두 4.5:1 이상. 위 값은 초안이며 P1에서 8가지 조합 전부 대비 검사 후 확정

### 2-3. 깜빡임 방지
- 페이지를 그리기 **전에** `<head>`의 작은 스크립트가 저장된 값(브라우저 저장소)을 읽어 `data-mode`, `data-palette`를 먼저 붙인다
- 저장 순서: 브라우저 저장소(즉시) → 로그인 상태면 내 정보(`users/{uid}.prefs`)에도 저장해 다른 기기에서도 유지
- 우선순위: 사용자가 고른 값 > 조직 기본값 > 기기 설정(모드) / `gallery`(색상)

## 3. 라이트/다크 토글 스위치

- 상단 메뉴 오른쪽에 **항상 보이는 스위치** (해 ☀ ↔ 달 🌙 아이콘이 손잡이 안에 있음)
- 크기: 56 × 32px, 누르는 영역은 48px 이상 확보
- 처음 상태: 기기 설정을 따름. 한 번 누르면 그때부터 사용자 선택을 기억
- 보기 설정 안에는 "기기 설정 따르기"로 되돌리는 선택지
- 접근성: `role="switch"`, `aria-checked`, 이름 "어두운 화면"
- 전환 효과: 색이 0.2초 동안 부드럽게 바뀜 (움직임 줄이기 설정이면 즉시)

## 4. 글자

| 항목 | 값 |
|---|---|
| 글꼴 | Pretendard (한글·영문), 일본어 Noto Sans JP, 중국어 Noto Sans SC 대체 |
| 기본 크기 | 18px (일반 웹보다 크게) |
| 글자 크기 3단계 | 보통 100% · 크게 115% · 아주 크게 130% (`--font-scale`) |
| 제목 | 28 / 22 / 18px, 굵기 700 |
| 본문 | 18px, 줄 간격 1.6 |
| 보조 | 15px, `--muted` |
| 한국어 줄바꿈 | 단어 단위 (`word-break: keep-all`) |

## 5. 간격·모양

- 간격 단위 4px: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64
- 모서리: 카드 2px(원본처럼 각지게), 패널 16px, 버튼 999px(알약)
- 누르는 영역 최소 48 × 48px
- 화면 폭: 휴대폰 < 640 · 태블릿 640~1023 · 데스크톱 ≥ 1024 · 최대 콘텐츠 폭 1280px, 양옆 여백 16px 이상

## 6. 움직임

| 동작 | 규칙 |
|---|---|
| 카드에 마우스 올림 | 위로 6px + 1.04배, 0.18초, 보조 버튼 나타남 |
| 카드 크게 보기 | 카드가 제자리에서 가운데로 **이어서** 커짐 (공유 요소 전환), 스프링 느낌 약 0.35초, 뒤는 흐려짐 |
| 닫기 | 원래 자리로 돌아감. 닫는 방법: ✕ 버튼, 뒷배경 클릭, Esc, 뒤로가기 |
| 움직임 줄이기 (기기 설정) | 모든 이동·확대를 끄고 0.15초 페이드만 |
